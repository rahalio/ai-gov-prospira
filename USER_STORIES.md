# Prospira — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Federal / provincial strategy coordinator

- As a coordinator, I want every initiative tagged to an action area and foundation gate, so that a research announcement cannot paint the whole prosperity agenda green.
- As a coordinator, I want the system to refuse on-track status when literacy coverage is unknown, so that we confront the 4%-confidence problem with numbers.
- As a coordinator, I want provincial non-participation flagged on national indicators, so that we do not invent coverage.

### Data strategy / privacy lead

- As a data strategy lead, I want public dataset releases counted only when machine-readable and privacy-reviewed, so that PDF dumps do not inflate unlock metrics.
- As a privacy lead, I want data-trust guidance items to track trustee diligence standards, so that fiduciary rhetoric becomes operational.

### Literacy and skills programme manager

- As a literacy lead, I want completions by audience segment, so that a civil-service course is not counted as population literacy.
- As a labour policy lead, I want EI coverage gaps recorded beside Future Skills seats, so that training announcements do not hide eligibility failure.
- As a programme manager, I want to attempt to mark “prepare Canadians” on-track without literacy foundation evidence and be refused, so that the gate has force.

### Accountability / standards officer

- As an accountability officer, I want automated decision systems that claim public trust to register their assessment basis, so that transparency is a system property.
- As a standards officer, I want international standards work blocked from “complete” while domestic rule gaps remain open, so that we set rules at home first.

### Scaleup / trade single-window operator

- As a single-window operator, I want capital and export-customer actions on separate tracks for each firm journey, so that we see which bottleneck dominates.
